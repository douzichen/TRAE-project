# 执行路径卡（TOOL-PATH-CARD）

> 用途：凡涉及外部系统（飞书 / GitHub / 云盘 / 邮件 / 数据库 / 第三方 API·CLI）的读写，动手前先填此卡。依据 [rules/04](../rules/04-roles-and-dispatch.md)「工具与执行路径判定」、[ADR-031](../docs/adr/ADR-031-tool-path-judgement.md)。
> 任何一栏填不出 = 口径未摸清：先停手补齐，不得动笔、不得派发。

| 项 | 填写内容 |
| --- | --- |
| ① 身份与归属 | 以谁的身份调用（会话代理 / 用户本人 OAuth / 服务账号）；资源归属主体是谁 |
| ② 能力探测 | 目标 CLI/API 是否存在、版本、所需 scope/权限；探测命令与实测结果 |
| ③ 通道路由 | 官方 API/CLI / 官方 SDK / 向用户交接；若用浏览器模拟，写用户明示授权的出处 |
| ④ 幂等键 | 写前查重命令（list/get）与判重键（名称＋父节点＋类型） |
| ⑤ 验收回读 | 写后回读命令与合格判据（命令＋退出码/关键输出） |
| ⑥ 回滚与授权 | 已产生副作用的回滚动作；用户授权主体 / scope / 有效期 / 回收动作（如 `auth logout`）；授权原话与确认时间 |
