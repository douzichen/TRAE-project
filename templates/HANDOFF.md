# 交接快照模板（docs/handoff/CURRENT.md 专用）

> 用法：复制下方代码块到 `docs/handoff/CURRENT.md` 填写；触发条件、衔接动作与新鲜度核对见 [rules/07](../rules/07-pending-and-handoff.md)（[ADR-013](../docs/adr/ADR-013-handoff-snapshot.md)）。
> 硬约束：限 ~30 行；只写 git log 与交付报告（D-1~D-7）看不到的内容，重复即删；模板只引用 rules/07 五要素、不复述（防双源漂移）。

```text
# 当前交接（最后更新：<日期>；与交付同一提交内更新）
## 目标
<一句话：当前在途任务要产出什么>
## 现状
<已验证到哪一步；未提交半成品的文件/路径/状态>
## 已定决策
<关键决策一句话＋理由；被否决方案一句话，详见 docs/adr/>
## 未决与坑
<阻塞、风险；待确认事项详情在 rules/07 台账，此处放指针>
## 下一步
<第一个具体动作（启动条件/负责人），而非一堆可能性>
## 沉淀与记忆收录
<本轮沉淀了什么/为何无需沉淀；详见最近交付的 D-4/D-6>
## 新鲜度核对
<填写时 HEAD 的简述；读者用 git log -1 --format='%h %s' -- docs/handoff/CURRENT.md 复核，不一致以 git log 为准>
```
