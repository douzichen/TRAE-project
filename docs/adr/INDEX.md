## 何时必须写 ADR

- 影响面大、不可逆、成本高的决策（规则库结构调整、技术选型、目录约定变更）。
- 有多个候选方案且被否决的方案后续可能被重新提出的情况。
- 小改动、措辞修订不写 ADR，避免噪音。
