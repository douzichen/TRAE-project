## 决策 A：外部 Agent 两层机制适配——平台分档

### A-1 平台分档表（落实乙 2.1 补偿）

外部 Agent 接入本机制前先自检平台能力，按下表分档执行，并在交付中**声明档位**；跨档假装执行即违规（依据：AGENT-ADAPTER.md「三步适配·按能力降级」表「降级必须声明，不得假装执行」「降级必须量化缺口，不得把降级当合规」）。

| 档位 | 判定标准 | 原始层做法 | 实测对应（依据） |
| --- | --- | --- | --- |
| **A 档：本地文件系统且持久** | 可写本地文件且文件跨会话留存（有实测或平台文档佐证） | 记本地未追踪原始层文件（等价 `.local/instruction-log.md`），同主会话口径（ADR-023:22） | TRAE 主会话（ADR-023 原样，非本 ADR 调整对象） |
| **B 档：可写文件但持久性未验证** | 可写本地文件，但沙盒/目录生命周期无记录，或平台存在拒写先例 | 可记；须声明「档位 B，持久性未验证」；每次开工先读上次文件，读不到即声明重建，不得假装续写 | WorkBuddy、豆包工作、千问（P-017/P-025/P-027 证可 clone 跑门禁，持久性未验证）；Codex（P-026 拒写 `.git/` 先例——须先探针验证 `.local/` 可写性，拒写即降 C 档）；DSH（无实测——开工先探针验证：可写即按 B 档声明，拒写或无终端降 C 档） |
| **C 档：无终端/无文件系统/会话即弃** | 无法写本地文件，或会话结束上下文即失 | **声明「原始层不适用，降级为会话内记忆＋回复回传」**；仅会话内观察＋按决策 C 回传脱敏候选；禁止把「已记原始层」写成口头合规 | 对话式平台（豆包 App 等；AGENT-ADAPTER.md「三步适配」降级表·无终端档先例） |

- C 档下「原始层」本义（本地留存全集观察）不成立：无文件即无聚类对象、上下文即弃（乙 2.1 判定原文）；降级后该平台的机制只剩「会话内观察＋脱敏候选回传」，如实声明，不冒充。
- B 档「持久性未验证」必须如实标注（依据：P-030，绝对化声明未附佐证即当事实属违规——「未验证」不得写成「持久」）。
- **各档同口径红线**（不因分档放宽）：只记用户显式偏好语句，不做无差别全录（rules/04「记忆收录」节 同文）；学习依据＝提炼层 rules/01「指令偏好」条目；外部 Agent 无权写 rules/01 或任何 `rules/` 分册（rules/04「跨项目运行模型」节·写入口唯一）。

### A-2 本地原始层合法性边界论证（落实乙 4.1 豁免＋禁令清单）

**为什么写 `.local/` 不破 ADR-015 只读红线与 ADR-017 写入口唯一**：

1. `.local/` 是 `.gitignore` 收录的未追踪本地文件（.gitignore:3），写入不产生 git 可见改动、不进入任何提交对象——**不构成 git 写入**；
2. ADR-015/rules/04「验证型 Agent 只读」红线的实质是**远端零变更**：该节「允许」项明列本地 commit 跑门禁（rules/04「验证型 Agent 只读」节·允许项），禁的是 `git push`、开 PR、改远端、上传（rules/04「验证型 Agent 只读」节·禁止项）——写一个永不入库的本地文件位于该红线允许侧之内；
3. ADR-017「写入口唯一」约束对象是「**规则文档**的新增与修改」（rules/04「跨项目运行模型」节·写入口唯一）——`.local/instruction-log.md` 非规则文档、非入库文件，不属该条款适用对象；
4. **字面豁免显式化**：rules/04「验证型 Agent 只读」节·「写入权：仅主 Agent。外部 Agent 确需写入时，须用户单独授权并记 ADR，否则视为违规」——本 ADR 即该 ADR；批准后豁免范围**仅限**「A/B 档下外部 Agent 自身副本内的本地未追踪原始层文件」，其余一切写入仍禁。rules/04「验证型 Agent 只读」节·写入权 原文零改动，豁免由 rules/04「验证型 Agent 只读」节新增条目承载（见 rules04-diff.md）。

**禁令清单（与豁免同批生效，缺一即违规）**：

1. 禁 `git add -f .local/`——强制入库＝绕过 `.gitignore` 变相上传（乙 4.1-①）；
2. 禁 `git push`、开 PR、上传任何文件到 GitHub（rules/04「验证型 Agent 只读」节·禁止项）；
3. 禁装 `.githooks`、禁配 deploy key / token / `gh auth login`（rules/04「验证型 Agent 只读」节·禁止项）；
4. `.local/` 内容（原话）不得出现在任何交付正文、报告、D-1 全文——防主会话引用时原话间接入库，违反 rules/08「敏感信息不入库」条（乙 4.1-④）；
5. 回传主会话仅限脱敏候选（决策 C），禁原话回传（乙 4.1-⑤）；
6. 除原始层文件外禁写任何文件，含规则文档与 AGENT-ADAPTER（rules/04「跨项目运行模型」节·写入口唯一；乙 4.1-⑥）；
7. clone 目录不得置于云盘同步区/平台自动快照区——防原话被静默上传第三方云（乙 4.2(b) 补偿；rules/14「内网与数据红线」节·禁止第三方服务「禁止第三方服务调用……外部 LLM 回传业务数据」红线精神直接适用）；
8. 跑门禁后核对 `git status`，有 diff 即 restore 并按「平台/命令/退出码」三栏记录——P-025 先例：link_check 设计内 `git add` 曾把平台差异自动进暂存区弄脏只读工作树（P-025）。

**禁令必要性的实测佐证**：P-026 证实 Codex 沙盒连 `.git/` 内写入都被拒——平台对写入的控制不可假设，未追踪文件一旦被强制 add 即绕过 `.gitignore` 全部防线；且 ADR-023:74 推翻条件 4「raw 层出现任何入库/推送违规 → 立即停用原始层」，禁令是保住整个机制不触发该引信的前提（乙 3.3 补偿）。

**并发豁免判定**（乙 4.3）：外部 Agent 写自身副本的未追踪文件，不与他人写同一文件，按 rules/13「只读不写不触发」判定不触发并发协议，照旧不认领 `docs/CLAIMS.md`（rules/04「验证型 Agent 只读」节·不参与并行；条文未变）；`.local/` 是各平台私有观察记录，不得误当共享台账。

### A-3 原始层/提炼层分界锚定（落实乙 P.2 防误读）

- 原话仅落本地原始层；**提炼层一律脱敏转述、禁止原话与可识别要素**（rules/01「指令偏好」条「一律脱敏转述，禁止原话与可识别要素」、rules/08「敏感信息不入库」条）——rules/04「记忆收录」节 与 rules/01「指令偏好」条 零改动，既有分界即防误读锚点；rules/04 新增条目内复述该分界一句（rules04-diff.md），防「禁止原话」被误读为原始层也禁原话。
- 提炼节奏维持已批版：同类重复 ≥2、当轮 `[偏好]` 确认，不改定期聚类（乙 3.2 判定：定期聚类交定时任务＝数据源否决理由①的复刻——定时任务运行在空沙箱且 `.local/` 不入 git 拿不到；维持已批版是当前证据下的稳妥选择，依据 ADR-023:19、schedules/daily-retro.md「平台约束」节）。

## 决策 C：回传协议

1. **触发**：外部 Agent 在服务用户过程中观察到用户**显式偏好语句**（与 rules/04「记忆收录」节 同口径：只记显式偏好语句，不做无差别全录；任务性指令、寒暄、一次性纠正不记——乙 1.1/3.1 的噪音风险随裁决①回退消解，此口径为防复发锚点）。
2. **回传内容仅限脱敏候选**，固定格式单行：

   ```text
   [指令观察候选] 日期 YYYY-MM-DD｜场景 <一句话>｜偏好 <脱敏转述>｜重复次数 N｜记录档位 <A/B/C>
   ```

3. **通道**：在交付 D-4「记忆收录说明」中单列「指令观察候选」小节（由 AGENT-ADAPTER 第七节承载；rules/15 正文零改动，不另设 D-8 或新 D 项）；主会话侧固定自检一句：「本轮 `.local/` 未进入任何入库文件与交付正文」（乙 3.3 补偿）。
4. **收口**：用户将候选带回主会话 → 当轮以 `[偏好]` 向用户确认（rules/01「提问分类」条、rules/07 用户是偏好最终确认人）→ 同类重复 ≥2 才触发提炼 → 按重级流程入 rules/01「指令偏好」（rules/04「记忆收录」节 全流程不变）。
5. **权限**：外部 Agent 无权写 rules/01（rules/04「跨项目运行模型」节·写入口唯一）；回传内容不得直接入册，主会话确认前仅作候选数据（乙 2.2 补偿）；拒绝即归档不追问（rules/04「记忆收录」节 同口径）。
6. **脱敏**：候选剔除可识别要素（人名、账号、路径、项目名、金额等），依据 rules/08「敏感信息不入库」条、rules/14「内网与数据红线」节·测试数据脱敏。

### 可推翻条件

1. A/B 档任一平台实测出现 `.local/` 入库/推送违规 → 该档外部原始层立即停用，该平台降 C 档只留会话内观察＋回传（联动 ADR-023:74 推翻条件 4）。
2. 回传候选噪音率高（试用期内误触发 `[偏好]` 确认 ≥2 次）→ 收窄为「仅纠错类语句回传」或停用回传通道，观察回归主会话自有义务（rules/04「记忆收录」节）。
3. 试用期复审（2026-12-21，与 ADR-023:25 合并）凭实证数据裁决：档位分布、候选条数、确认入册数、误触发数；低产出即降级或回退外部适配层。
4. AGENT-ADAPTER 超 130 行上限且无法压缩 → 增补节外移为独立文档或收缩条款；上限数字变更须走本 ADR 修订（重级，AGENTS.md「任务分级」节）。
