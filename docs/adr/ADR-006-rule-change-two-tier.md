# ADR-006：规则条款变更改为"是否改变含义"两级制

- 日期：2026-11-18
- 状态：已接受

## 背景与问题

此前 `rules/06-quality.md` 把"修改规则条款"一律定为**重级任务**：必须走对抗审查 + ADR + D-1~D-6 全量交付。制定时的考虑是"规则是铁律，改规则必须最谨慎"，方向上没错，但把**条款含义**与**文字表述**放在同一档，实践中出现三个问题：

1. **成本倒挂**：改一个错字、修一个死链、把一个长句拆短、把原文在分册间搬运，也要写 ADR、派对抗审查、出全量交付清单，流程成本远高于改动本身的价值。
2. **阻碍规则库自维护**：规则库本身需要持续纠错、对齐链接、控制体积（见 ADR-004）。重流程让这类维护被不断推迟，错字和死链长期留存，反而侵蚀规则的可信度。
3. **催生规避行为**：为了避免走重流程，修改者倾向于"顺手改、不声张"，比"明确区分两级并留痕"更危险。

需要回答的问题：**如何在不降低语义变更审查强度的前提下，让表述层修订可以低成本、可追溯地完成？**

## 候选方案

| 方案 | 做法 | 优点 | 缺点 |
| --- | --- | --- | --- |
| A 一律重级（维持现状） | 任何规则条款改动都走对抗审查 + ADR + D-1~D-6 | 不会漏审语义变更；规则最保守 | 错字/链接/搬运也付全额成本；维护被拖延，错字死链长期留存；实际执行中容易被"顺手改"绕过，反而失去留痕 |
| B 一律轻级 | 所有规则改动只需通过机械门禁 | 维护成本最低 | **直接取消语义变更的审查**，等于放弃"改规则要谨慎"这一前提；无 ADR 就无法回溯"谁改了含义、为什么"，审计资产断档 |
| C 按是否改变含义两级（**采纳**） | 改变含义→重级；不改变含义的表述修订→四道机械门禁 + 提交信息注明"仅表述"；边界争议按重级处理，举证责任在修改者 | 审查强度与实际风险匹配；维护成本降到可执行；争议时默认从严，不留"自我裁定"的口子 | 需要修改者自行判断"是否改变含义"，存在误判空间；依赖机械门禁与复审机制兜底 |

## 决策

采纳方案 C，落地为 `rules/06-quality.md`「任务分级触发」的例外条款，以及 `AGENTS.md`「规则库结构约定」第 1 条。

**重级——改变条款含义**：新增规则、删除规则、放宽或收紧既有要求、改变优先级或阈值 → 须对抗审查 + ADR + D-1~D-6 全量交付。

**轻级——不改变含义的表述修订**：错字、标点、链接、把长句拆短、分册间搬运原文 → 只需通过 `secrets_scan` / `md_check` / `link_check` / `context_budget` 四项机械门禁，并在提交信息注明"仅表述"。

**边界规则（关键取舍）**：复审者若认为该修订可能影响含义，一律按重级处理，**举证责任在修改者**。理由：含义是否改变不由修改者单方裁定——这正是"球员兼裁判"的老问题（见 ADR-005）；把举证责任压给修改者，使模糊地带自动落入从严一侧，而不是靠自觉。

## 否决项及原因

- **否决 A"一律重级"**：它不是"更安全"，而是"安全到没人执行"。当合规成本显著高于改动价值时，实际结果是绕开流程而非遵守流程，留痕反而更差。
- **否决 B"一律轻级"**：语义变更失去对抗审查与 ADR，等于拆掉 ADR-005 建立的审查分工；且"改一个阈值"与"改一个错字"在后果上差着数量级，不应同档。
- **否决"以改动行数/文件数作为分级依据"**：改一个"≤"为"<"只有 1 个字符，却可能改变整条规则的含义；行数是代理指标，与真实风险不对应。

## 什么条件下应推翻本决策

1. **出现"轻级修订被用来夹带语义变更"的实际案例**（以"仅表述"为名改阈值、改"必须/可以"、删减限定条件等）——立即收紧为"规则条款改动全部重级"，并复盘机械门禁为何未能识别；
2. 复审机制实际失效（例如长期无复审者、轻级提交无人复核）——两级制的前提是"有独立复审"，前提不存在则退回一律重级；
3. 机械门禁四项中任一项长期不可用或被跳过——轻级通道失去兜底，应暂停轻级；
4. 规则库进入冻结/归档阶段、不再需要日常维护——两级制的收益消失，可按需简化回单级。

## 影响与代价

- **正面**：错字、死链、体积超限可在分钟级修复；语义变更的审查强度不降反升（边界争议默认按重级）。
- **代价**：修改者需先做一次"是否改变含义"的判断，存在误判成本；复审者承担边界裁定职责，需要可追责的"仅表述"标记。
- **二阶影响**：机械门禁成为轻级通道的**唯一**技术兜底，其可靠性直接决定本决策能否成立；`md_check` 的内容级关键词校验与审计资产只增不减检查不可弱化。
- **三阶影响**：规则库维护频率上升，可能带来分册体积增长——仍受 ADR-004 的上下文预算约束，不得以"反正是轻级"为由绕过 `context_budget`。
