# 并行认领台账

> 用途：多 Agent 并行作业时的**唯一认领台账**，规则见 [rules/13](../rules/13-concurrency-and-lifecycle.md)。
> 本文件入库、可被所有 Agent 读取；认领、更新、注销都在本表内进行。**只增行、不删行**（审计痕迹）。

## 填写口径

| 字段 | 口径 |
| --- | --- |
| 认领人 | `<角色>-<会话标识>`，如 `主-7f3a`、`子-税审-2b91`；同一会话跨轮不变，不得只写"我""Agent" |
| 文件或目录 | 仓库相对路径；目录以 `/` 结尾（如 `docs/`）。具体文件与目录重叠时，**具体文件优先** |
| 开始时间 | `YYYY-MM-DD HH:MM`，时区 `+08:00`（Asia/Shanghai） |
| 预计结束 | 同上格式；超过该时间 **2 小时**未更新即视为过期，任何 Agent 可回收 |
| 状态 | 仅 `进行中`／`已完成`／`已放弃`；注销只改状态，**不删行** |

## 操作要点

- **认领前**：先读本表；目标已有 `进行中` 行即不得开工；跨分支/跨机器作业须先提交并推送本表到 `origin/main` 后才可开工。
- **注销**：子 Agent 自检通过后仍保持 `进行中`，主 Agent 审查通过后再改 `已完成`；放弃则改 `已放弃`。
- **冲突**：发现同一具体文件有两行 `进行中`，或文件已被他人改动，后到者立即停止、不覆盖，报主 Agent 裁决。
- **示例**：`子-税审-2b91｜docs/CLAIMS.md｜2026-11-18 10:10｜2026-11-18 10:40｜进行中`
