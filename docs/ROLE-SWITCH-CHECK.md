# 角色切换自检（开工前逐条作答）

> 目的：把"主审/执行分离"从口号变成**可检产物**。这不是参考资料，而是开工前的强制自检表。
> **未回答即开工 = 违规**；只打勾不写答案 = 未回答。

## 使用方式

- 开工前对下列 5 个问题**逐条写出答案**（每问都必须有文字答案，不能只打勾）。
- 答案须随交付一并粘贴（见 [AGENT-ADAPTER.md](AGENT-ADAPTER.md) 顶部的开工前置条件），供复审方核对。
- 任一问题答不出或答"否"，按 [06 问题与决策质量](../rules/06-quality.md) 与 [12 上下文预算](../rules/12-context-budget.md) 的降级口径声明缺口，不得静默跳过。
