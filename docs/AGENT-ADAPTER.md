| 本仓库机制 | 若你没有该能力 | 降级做法 |

## 三、四条不可偏离的实质（改名也不许改）

> **重要：以下四条是"最小集"，不是全部红线。**全部红线共 11 条，见 [AGENTS.md](../AGENTS.md) 的"核心红线速查"表；不得只遵守本节而跳过其余条款（尤其是 03 技能同步、08 对齐与版本管理、11 回滚）。

1. **用户是财税从业者**：业务口径以用户为准；技术方案由你负责，不把技术选择推回给用户；不附和，判断有误直接指出。
2. **财税判断必须写出政策名称与具体条款并核实清楚**；核实不到就明确写"尚未核实到对应条款，不作结论"，不得凭记忆编条款号。
3. **收到指令先复述需求并列出待明确边界**，确认后再动手。
4. **审计资产永不删除**：坑账本、审查结论、ADR、交付记录。降级可以，删减不可以。

## 四、交付格式（与 TRAE 版一致）

按 [rules/15-delivery-dod.md](../rules/15-delivery-dod.md) 的 D-1~D-7 汇报：新增段与全文、改动清单、对账结果、收录说明、验证与同步状态、沉淀与待确认。禁止"如需我再贴一遍请说"式推迟。

## 五、发现规则有问题时

- **不要私自改规则，也不要推送**：验证型 Agent 一律只读——可在本地副本试改并跑门禁验证，但**不得 `git push`、不得开 PR、不得上传任何文件**（用户明确限制，见 [rules/04](../rules/04-roles-and-dispatch.md)）。**每个新 clone 都要重新执行一次** `git config --local credential.helper ""`，并用 `GIT_TERMINAL_PROMPT=0 git push --dry-run origin main` 自证失败——这是仓库级设置，重 clone 即失效，全局凭据会重新生效。发现问题时在交付里写"哪条与我的平台冲突、建议如何降级"，由本项目维护者决定是否合并。
- 直接改本地副本会导致本仓库与其他环境分叉（历史坑 P-005）。

## 七、指令偏好学习机制（外部 Agent 适配，[ADR-024](adr/ADR-024-external-agent-instruction-observation.md)，2026-11-21 起，试用期至 2026-12-21）

> 本节属**生效条款**，不是建议；落地依据：[rules/04](../rules/04-roles-and-dispatch.md)「验证型 Agent 只读」节「外部 Agent 本地原始层」条。与第六节、S-004 的使用顺序见本节末。

**机制职责**：你对用户偏好的学习依据＝提炼层 [rules/01](../rules/01-user-profile.md)「指令偏好」条目；观察义务与主会话同口径——**只记用户显式偏好语句，不做无差别全录**（[rules/04](../rules/04-roles-and-dispatch.md)），任务性指令、寒暄、一次性纠正不记。金丝雀复述只证明读到仓库副本（[S-004](../skills/S-004-rulebase-onboarding.md) 口径），不证明平台注入或机制生效，禁止据此推断。

**平台分档**（开工自检并在交付中声明档位；降级必须声明，不得假装执行——上文第二节第 3 步原则）：

| 档位 | 判定 | 原始层做法 |
| --- | --- | --- |
| A 档 | 本地文件系统且持久（有实测或平台文档佐证） | 记本地未追踪原始层文件（等价 `.local/instruction-log.md`） |
| B 档 | 可写文件但持久性未验证（含沙盒拒写先例 P-026） | 可记；声明「档位 B，持久性未验证」；每次开工先读旧文件，读不到即声明重建，不得假装续写 |
| C 档 | 无终端/无文件系统/会话即弃 | **声明「原始层不适用，降级为会话内观察＋回传」**，不得假装已记 |

**原始层禁令**（缺一即违规）：禁 `git add -f .local/`；禁 push/开 PR/上传（上文第五节）；`.local/` 内容不得出现在任何交付正文；除原始层文件外禁写任何文件；clone 目录不得置于云盘同步区/平台自动快照区；跑门禁后核对 `git status`，有 diff 即 restore 并按「平台/命令/退出码」记录（P-025 先例）。本组禁令**不覆盖** [rules/04](../rules/04-roles-and-dispatch.md)「验证型 Agent 只读」允许清单内的动作（clone/pull/读取/试跑门禁）——`git pull --ff-only origin main` 同步本地副本与门禁散改还原（restore）**无需请示授权**；旧副本当权威的危险大于 pull 的写面（P-018），把禁令解释为冻结本地副本属过宽解释（2026-11-21 WorkBuddy 首验发现，主审修正，用户批准）。

**回传协议**：观察到用户显式偏好时，在交付 D-4 收录说明中**单列一行**固定格式（仅脱敏候选：剔除人名、账号、路径、项目名、金额等可识别要素，[rules/08](../rules/08-alignment-and-versioning.md)；禁原话回传；无权写 rules/01，候选不得直接入册，由用户带回主会话按 [rules/04](../rules/04-roles-and-dispatch.md) 流程当轮 `[偏好]` 确认）：`[指令观察候选] 日期 YYYY-MM-DD｜场景 <一句话>｜偏好 <脱敏转述>｜重复次数 N｜记录档位 <A/B/C>`
